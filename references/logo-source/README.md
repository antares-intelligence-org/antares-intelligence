# Logo sources

These are the editable sources for the stacked Antares Intelligence lockups, for dark and light backgrounds. The wordmark is live text, ANTARES in Space Grotesk and INTELLIGENCE in Host Grotesk, both at weight 700. The sources load those fonts from Google Fonts, so they render correctly only where web fonts are allowed.

The stacked files in `brand/logos/` are generated from these sources by `outline.py`, which converts the wordmark to vector outlines so the logo needs no fonts and makes no network request. Edit a source here, then regenerate. [CONTRIBUTING.md](../../CONTRIBUTING.md) has the exact commands.

The horizontal lockups have no source here. They are drawn as outlines and edited directly in `brand/logos/`.
